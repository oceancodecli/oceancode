# Security Policy

Veloxx Labs and the OceanCode community take security vulnerabilities seriously. We appreciate your efforts to responsibly disclose any issues you find.

---

## Supported Versions

Only the latest release of OceanCode receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1.0 | No                 |

---

## Reporting a Vulnerability

If you discover a security vulnerability in OceanCode, please do **NOT** open a public issue or discuss it in public channels.

Instead, please report vulnerabilities by:

1. Submitting a private report via [GitHub Security Advisories](https://github.com/oceancodecli/oceancode/security/advisories/new).
2. Emailing the maintainers directly at security@veloxxlabs.org with:
   - A description of the vulnerability and its potential impact.
   - Steps to reproduce or proof-of-concept code.
   - Any proposed remediation steps or mitigations.

---

## Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for investigation and remediation.
- Once fixed, we will publish an advisory credit acknowledging your contribution (unless you prefer to remain anonymous).
